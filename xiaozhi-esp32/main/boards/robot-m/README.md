
# Robot-M / 大头

## 名称与唤醒

- 机器人名称：大头。
- 本地唤醒词：你好大头；中文拼音：`ni hao da tou`。
- 板级 `config.json` 使用 MultiNet `mn6_cn`，初始识别阈值为 20%，关闭原来的 `wn9_nihaoxiaozhi_tts` 模型。
- `CONFIG_CUSTOM_WAKE_WORD_DISPLAY` 为“你好大头”，是唤醒事件文本，不是云端角色名称，也不会自动替换整个屏幕界面的名称。
- 云端聊天自称需要服务端角色配置配合；本地资源包不能保证回答时自称“大头”。保留 `robot-m` 板型标识以保持 OTA 兼容性。

## 构建与验证

在已加载 ESP-IDF 环境的 `xiaozhi-esp32` 目录执行：

```bash
python3 scripts/build.py robot-m --name robot-m
```

构建会生成 `build/xiaozhi.bin` 和 `build/generated_assets.bin`。更新设备时必须同时更新应用和资源；仅执行 `app-flash` 不会更新唤醒资源。确认串口后使用 `idf.py -p PORT flash`，再查看启动日志是否选择 MultiNet 并加载“你好大头”。

真机检查：安静和有背景噪声时的唤醒成功率、误唤醒、播放期间的打断，以及断网后的本地识别。离线识别成功不代表云端对话可用。

## 基础离线语音（ESP-SR）

Robot-M 默认启用 `CONFIG_OFFLINE_VOICE`。使用乐鑫 ESP-SR 的 `mn6_cn` 和 AFE，启动时先加载本地资源，再尝试联网。它是固定命令识别，不是离线大模型聊天。

| 口令 | 本地行为 |
| --- | --- |
| 你好大头 | 无 Wi-Fi 或云端语音连接失败时，播放“我在，现在没有网络。” |
| 音量大一点 | 输出音量增加 10，上限 100 |
| 音量小一点 | 输出音量减少 10，下限 0 |
| 停止动作 | 取消定时步态并调用现有舵机停止接口；该接口关闭扭力，测试时需支撑机器人 |

固定口令在本地识别运行时可直接说出，不依赖云端。提示音播放期间暂时暂停识别，播放结束后恢复。语音停止不是硬件急停，不能替代物理断电或机械保护。

有已保存 Wi-Fi 时，连接超时不自动切到配网，继续后台扫描重连；没有凭据时仍可配网，并保留本地识别。启动时若存在待下载资源 URL，会先保留原资源更新流程，这种情况下冷启动离线识别尚有限制。

网络断开或云端语音通道关闭时停止动作，已排队的旧运动请求失效，恢复连接后不自动续走。不新增离线行走指令。

## 断网验收

1. 在线待机后关闭机器人所连热点，喊“你好大头”，确认听到本地提示。
2. 提示结束后再次唤醒，并分别测试“音量大一点”“音量小一点”。
3. 在热点关闭时重启机器人，重复本地唤醒测试。
4. 恢复热点，确认自动连接并恢复聊天。
5. 支撑好机器人或脱离负载后测试“停止动作”，以及断网停止；不要在无保护的站立状态测试关闭扭力。

本地提示音 `main/assets/common/offline.ogg` 由 macOS Ting-Ting 语音生成，单声道 16 kHz Opus，60 ms 帧，仅离线功能启用时链接。

已完成完整构建、烧录和启动日志检查：MultiNet 和四条命令在联网前初始化，联网激活成功。断网/冷启动断网、噪声下识别、机械停止和重连仍需真机逐项验收。全套主机测试 83 项中 82 项通过，剩余失败为已有板型菜单排序检查。
